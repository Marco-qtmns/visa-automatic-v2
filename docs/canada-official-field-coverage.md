## Explicit value semantics

- Unknown/null means unresolved and does not satisfy a required or conditional gate.
- A negative boolean is stored as `false`; it is not treated as missing. In particular, `Não`/`No` for other citizenship persists as `has_other_citizenship=false` and creates no country row.
- Not applicable is distinct from No. The current binary IMM5257 controls reject Not applicable where the generated form cannot represent it.
- Country controls persist normalized ISO alpha-3 codes. Enumerated biography values are validated before typed persistence.
- Manual canonical changes create immutable `CanonicalValueRevision` rows and retain source reference, reviewer and prior value.

## Known workflow boundaries

Routine scalar blockers now have case-worker inputs in Canonical intake. Collection records whose correctness depends on multi-row identity/profile resolution remain handled through reviewed imports; their low-level repair editor and endpoints are administrator-only. A blocker without a safe direct scalar input is deliberately displayed as non-clickable guidance rather than linking to an unrelated control.
